# 🧠 Customer Churn Prediction
A full-stack Deep Learning web application that predicts customer churn using an Artificial Neural Network (ANN). Built with a modular ML pipeline, an intuitive Streamlit web UI, and designed for real-world deployment.

## 🚀 Project Overview
This project showcases an end-to-end deep learning solution to predict whether a customer will leave a bank based on attributes like geography, credit score, age, balance, and more.

Following industry-standard practices, it combines a clean modular pipeline with a user-friendly web interface to demonstrate the application of ANN models in business decision-making.

## 📌 Features
✅ Deep Learning Model: ANN built with TensorFlow/Keras using a structured, modular architecture (Data Ingestion → Data Preprocessing → Model Training → Evaluation → Prediction).

🌐 Web Application: Built with Streamlit for an interactive and modern UI; allows real-time predictions from user inputs.

🛠️ Modular ML Pipeline: Clean and maintainable Python code organized into reusable components under src/.

📁 Model Deployment Ready: Easily portable using Streamlit; can be extended for Dockerization and cloud deployment.

🔍 Model Insights: Includes evaluation metrics like accuracy, confusion matrix, and classification report for performance validation.

📊 Data Visualization: Exploratory Data Analysis (EDA) included to understand feature distributions and correlations.
